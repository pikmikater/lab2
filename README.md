## ✅ Завдання 1: Аналізатор лог-файлів

### Функція `analyze_log_file(log_file_path)` повинна:
1. Прочитати кожний рядок текстового лог-файлу HTTP-сервера.
2. Визначити кількість входжень унікальних HTTP-кодів відповіді (наприклад: 200, 404, 500).
3. Зберегти результати у словнику, де ключ — код відповіді, значення — кількість входжень.
4. Обробити винятки:
   - `FileNotFoundError` — якщо файл не знайдено.
   - `IOError` — якщо сталася помилка читання файлу.
5. Повернути словник з результатами аналізу.

## ✅ Завдання 2: Генератор хешів файлів

### Функція `generate_file_hashes(*file_paths)` повинна:
1. Приймати довільну кількість шляхів до файлів.
2. Відкрити кожен файл у бінарному режимі.
3. Обчислити SHA-256 хеш вмісту файлу.
4. Зберегти результати у словнику:
   - ключ — шлях до файлу,
   - значення — SHA-256 хеш у шістнадцятковому форматі.
5. Обробити винятки:
   - `FileNotFoundError` — якщо файл не знайдено.
   - `IOError` — якщо сталася помилка читання файлу.
6. Повернути словник з хешами файлів.

## ✅ Завдання 3: Фільтрація IP-адрес з лог-файлу

### Функція `filter_ips(input_file_path, output_file_path, allowed_ips)` повинна:
1. Прочитати IP-адреси з кожного рядка лог-файлу.
2. Перевірити, чи входить кожна IP-адреса до списку дозволених IP (`allowed_ips`).
3. Порахувати кількість входжень дозволених IP-адрес у файлі.
4. Записати результати у файл у форматі: `<IP-адреса> - <кількість входжень>`
